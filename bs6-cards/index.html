Using these

Each card is a standalone page. Copy the markup out of the one you want and drop it in — every variant needs only Bootstrap 6’s CSS. The only JavaScript in this pack is the shared colour-mode toggle.

Making a whole card clickable

Do not wrap the card in an anchor. It swallows any button inside it and gives the link an accessible name made of the entire card’s text. Put one link on the title and stretch it with a pseudo-element instead — the whole surface becomes clickable, the tab order stays sane, and the link is announced as its title.

Equal heights

h-100 on the card plus d-flex flex-column on the body, then mt-auto on the action. That pins buttons to the bottom so a row of cards with different amounts of copy still lines up.

Media

Give the media area a fixed aspect-ratio and use object-fit: cover on real images. Without it the card resizes as each image decodes, which is most of the layout shift on a typical card grid.

Grids

The last variant uses repeat(auto-fill, minmax(17rem, 1fr)) rather than column classes. It reflows at whatever width the content needs instead of at breakpoints you picked in advance, which matters when a card grid sits inside a sidebar layout.
