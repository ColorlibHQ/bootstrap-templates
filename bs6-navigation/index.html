Bootstrap 6 Navigation

Ten form layouts covering the shapes real projects need — contact, sign-up, booking, multi-step, verification and filtering. Between them they use every form component Bootstrap 6 added over v5.

01

Standard navbar

The v6 baseline. There is no .navbar-collapse any more — the mobile menu is a native <dialog class="drawer"> that navbar-expand inlines on desktop.

02

Dropdown menus

Dropdown is now Menu. No .dropdown wrapper, no .dropdown-toggle — the toggle and the .menu are siblings, positioned by Floating UI.

03

Nav overflow

New in v6, no equivalent in Bootstrap 5. Items that do not fit fold into a menu automatically as the viewport narrows.

04

Tabs and pills

Tab panels with fade transitions, plus the pill variant. Markup and the JS API are unchanged from v5.

05

Sidebar rail

A vertical navigation rail for applications. Note .navbar-nav is column by default — navbar-expand is what makes it a row.

06

Centered wordmark

Editorial masthead: brand centred with the navigation split either side. Common on magazines and portfolios.

07

Breadcrumbs and pagination

Both changed in v6: links take .breadcrumb-link, and separators are real .breadcrumb-divider elements rather than ::before pseudo-elements.

08

ScrollSpy contents

ScrollSpy was rebuilt on IntersectionObserver. The offset option is gone; use top-margin to clear a sticky header.

Using these

Each form is a standalone page. Copy the markup out of the one you want and drop it into your project — the only requirements are Bootstrap 6’s CSS and, if you use Combobox, Datepicker, OTP, Chips or Range, its JavaScript bundle.

Bootstrap 6 is ESM-only, so the script tag needs type="module" and there is no window.bootstrap global. Importing the bundle for its side effects is what registers the data-attribute API.

Validation

.needs-validation and .was-validated are gone. Put data-bs-validate and novalidate on the form and native :user-invalid handles the styling — feedback only appears after the visitor has actually interacted with a field. Add data-bs-validate="valid" if you also want success styling.

A gotcha worth knowing

Combobox’s search and multiple options are typed booleans, so a bare attribute fails config validation. Write data-bs-search="true", not data-bs-search. Bare marker attributes are correct for data-bs-otp, data-bs-chips, data-bs-strength and data-bs-validate.
